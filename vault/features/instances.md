# Инстансы

## Что это

Один nit-gui и несколько серверов OpenCode — инстансов. Меню показывает, какие
инстансы доступны, чем они отличаются и что каждому нужно: голый OpenCode или ещё
сервис nit-gui с озвучкой, диктовкой и орфографией.

Главная задача меню — снять путаницу: «какое место занимает наше прилложение во всей
этой схеме». Окно, которое только рисует схему и ничего не даёт редактировать, — не
ответ.

Подключение нового инстанса — два шага: получить в одном nit полный ключ/url/адрес в
буфер обмена и вставить в другой. У каждого инстанса свой выбор директории, потому что
машины разные.

## Состояние

Факт, не желаемое:

- Один nit-gui обслуживает несколько OpenCode-серверов; конфиг `instances.json`,
  маршрутизация по `X-Nit-Instance`, состояние по инстансам — `docs/decisions.md`,
  2026-11-06.
- Меню редактирует инстансы из браузера, конфиг и секреты остаются на сервере —
  `docs/decisions.md`, 2026-11-07.
- Хостовый TTS подключён через хаб и piper — `docs/decisions.md`, 2026-11-07.
- «Подключение в два шага» через буфер обмена в `docs/decisions.md` не описано.

## Критерии приёмки

- Меню инстансов перечисляет доступные инстансы и показывает состояние связи.
- Для каждого инстанса видно, что ему нужно: только OpenCode или ещё сервис nit-gui с
  речью и орфографией.
- Из меню можно добавить, изменить и удалить инстанс; приложение не перезапускается.
- Новый инстанс подключается двумя шагами: скопировать строку подключения в одном nit и
  вставить в другом.
- У каждого инстанса свой выбор директории.
- Хостовый TTS в меню показан как включённый, а не `off`.
