# Constraints

## Что это

Границы, которые пользователь назвал явно.

Работа идёт только с `nit` и `nit-gui`; сторонние проекты вроде `pero` не трогаем.
Приложение — чат, а не дашборд. Агент не вываливает на пользователя свою кухню:
вызовы инструментов и рассуждения лежат в свёрнутом блоке, а не серыми блоками посреди
ответа. Исходники HTML-вставок и диаграмм в чате не показываются.

Из брифа, не из цитат: нет терминала, файлового менеджера, IDE и панели VCS; нет базы
данных, серверных аккаунтов и телеметрии; нет второго движка чата — OpenCode остаётся
единственным источником сессий.

## Состояние

Факт, не желаемое:

- HTML не попадает в DOM приложения: markdown рендерится без raw-HTML, превью — в
  `iframe srcdoc` без `allow-same-origin` — `docs/decisions.md`, 2026-11-04.
- Пароль OpenCode не уходит в браузер: редактирование на прокси — `docs/decisions.md`,
  2026-11-04.
- Отдельного терминала, файлового менеджера, IDE и VCS в коде нет.

## Критерии приёмки

- В интерфейсе нет панели терминала, файлов, IDE или VCS.
- Нет запросов к сторонним CDN из превью.
- Нет второго движка чата: все сообщения идут через OpenCode.
- Рассуждения и вызовы инструментов свёрнуты; в транскрипте нет серых блоков, о смысле
  которых пользователь не знает.
- У HTML-вставки и диаграммы нет кнопки «показать исходник».
- Приложение не показывает себя как дашборд: нет отдельной аналитической панели.
