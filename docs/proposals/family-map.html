Выбери узел

Приложения не вызывают друг друга. Они делят домен и cookie, папку на диске и URL с параметром.

Шов между приложениями — только переход, а не вызов. Из чата в файл: ?open=путь&lines=12-20. Из drop в файл: тот же ?open=. Всё остальное — HTTP через гейт.
