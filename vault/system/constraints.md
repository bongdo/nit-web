# Constraints

## Что это

Границы, которые пользователь назвал явно.

Приложение не делает: терминал, файловый менеджер, IDE, панель VCS. Нет аккаунтов,
телеметрии и второй модели чата. OpenCode остаётся единственным источником правды.
HTML-превью не получает `allow-same-origin`. Фрагменты не тянут внешние файлы и CDN:
песочница самодостаточна.

## Критерии приёмки

- В интерфейсе нет панели терминала, файлов или VCS.
- Нет запросов к сторонним CDN из превью.
- Нет второго движка чата: все сообщения идут через OpenCode.
