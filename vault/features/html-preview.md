# HTML preview

## Что это

HTML-фрагменты из ответов агента показываются живым превью, а не текстом и не серой
коробочкой с кнопкой Preview. Элемент выглядит нативно, как часть чата: без рамки,
без подписи, без переключателя.

Агент знает, что может отвечать HTML-фрагментами, и делает это, когда нужно что-то
визуализировать — «а это почти всегда». Постобработки, которая меняет цвета и
контраст, нет: она уже сделала текст нечитаемым.

## Состояние

Факт, не желаемое:

- HTML рендерится в `iframe srcdoc` с `sandbox`, без `allow-same-origin` — решение
  `docs/decisions.md`, 2026-11-04.
- Нативные элементы без коробки/Preview и снятая постобработка в `docs/decisions.md`
  не зафиксированы.

## Критерии приёмки

- Fenced-блок `html` с разметкой показывает живой результат без рамки и без кнопки
  Preview.
- У блока нет кнопки «показать исходник».
- Скрипт внутри превью не читает DOM приложения.
- Слайдеры и другие интерактивные элементы в превью работают.
- Агент отвечает HTML-фрагментом на просьбу визуализировать, без напоминания.
- Кнопки и текст в превью читаются: постобработка не делает фон и контролы белыми.
