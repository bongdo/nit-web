# HTML preview

## Что это

Полные HTML-документы и фрагменты из ответов агента показываются живым превью, а не
текстом. Превью живёт в `iframe` с `sandbox` без `allow-same-origin`: скрипты внутри
не достают до приложения, cookies и localStorage.

Пользователь не хочет видеть исходник HTML-вставки в чате.

## Связи

- [[chat]] — транскрипт.
- [[diagrams]] — следующий тип превью.
- [[constraints]] — границы песочницы.

## Критерии приёмки

- Fenced-блок с `<!doctype html>` рендерится как страница в превью.
- У блока нет кнопки «показать исходник».
- Скрипт внутри превью не читает DOM приложения.
