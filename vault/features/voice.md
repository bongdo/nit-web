# Голос

## Что это

Диктовка заполняет инпут, а не отправляет сообщение: пользователь говорит, текст
дописывается к уже набранному, прошлый ввод не стирается. Пока идёт распознавание,
микрофон показывает, что он слышит, — уровень и текст в реальном времени, без паузы в
полминуты.

Озвучка — одна из основных функций. Ответ начинает звучать, не дожидаясь конца
стрима. Технический жаргон — код, пути, адреса — не читается дословно, но остаётся
частью контекста.

Серверные модели держат прогретыми: «я за то, чтобы иметь выдачу всего как можно
быстрее».

## Критерии приёмки

- Нажать микрофон: появляется анимация уровня, текст растёт по мере речи, сообщение не
  отправляется, прошлый текст в инпуте сохраняется.
- Первый звук распознавания приходит без паузы в полминуты; серверная модель уже
  прогрета.
- Ответ начинает звучать до конца стрима; первый сегмент — около секунды.
- Блок кода, путь и адрес не читаются посимвольно, но слышно, что это блок кода, файл
  или ссылка.
- Кнопка озвучки стоит под ответом и озвучивает ответ целиком; выделенный текст
  озвучивается отдельно.
- Firefox: диктовка работает через серверный STT, без Web Speech.

## Открытые вопросы
