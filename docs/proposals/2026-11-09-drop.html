Как это работает

Каждая публикация — это папка с файлами и метаданными. Если внутри есть index.html, drop показывает приложение. Если есть .md — открывает читалку.

Агент кладёт файлы командой drop docs ./vault. Ссылка в ответе кликабельна, как обычный URL.

Переходы

Относительная ссылка api.md открывает соседний документ в той же читалке. Картинки и вложения ведут на сырые файлы, внешние ссылки остаются внешними.

  • Один пароль на nit, pero, term и drop.
  • HTML-приложения запускаются в sandbox без доступа к API nit.
  • Просроченное удаляется само.

Почему агент узнает

Команда в bin/ попадает в PATH, а правило в AGENTS.md говорит: если пользователю нужно показать страницу, приложение или доки — публикуй через drop и отдай ссылку.
