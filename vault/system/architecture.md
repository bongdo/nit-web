# Architecture

## Что это

Один Go-бинарник со встроенным React-бандлом. Go проксирует HTTP и SSE к сервису
OpenCode, добавляет авторизацию, вложения, диктовку, озвучку и состояние интерфейса.
Сессии, сообщения, модели и агенты принадлежат OpenCode; приложение их не хранит.

Инстанс — один сервер OpenCode за приложением: `local`, `url` или `ssh`. Переключение
инстанса меняет пространство сессий и агентов.

## Связи

## Критерии приёмки

- Остановка приложения не теряет сессии и сообщения.
- Новый инстанс добавляется без перезапуска приложения.
- Приложение не открывает второй канал к моделям.
