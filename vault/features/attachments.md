# Вложения

## Что это

К сообщению прикрепляются картинки и PDF, а также другие файлы: аудио, видео, GIF.
Три пути одинаково работают — скрепка, вставка из буфера и drag-and-drop. Картинка
видна и до отправки, и в истории чата. У каждого популярного типа файла своя иконка;
неизвестный тип получает общую.

Файл уходит только по Send: выбранный и передумавший не остаётся мусором на сервере.

## Состояние

Факт, не желаемое:

- Вложения грузятся при отправке, лимит 20 MiB, картинки/PDF/прочее рисуются в
  транскрипте — `docs/decisions.md`, 2026-11-06.
- Общий компонент превью: картинка/GIF, аудио и видео с плеером, PDF, карточка
  скачивания с иконкой типа — `docs/decisions.md`, 2026-11-06.

## Критерии приёмки

- Вставить картинку из буфера, прикрепить скрепкой и перетащить в окно — все три пути
  дают одно вложение.
- До отправки видна миниатюра; после отправки картинка видна в истории чата.
- PDF открывается, mp3 и видео играют, GIF анимируется.
- Файл, который не отправили, не остаётся на сервере.
- У изображения, PDF, архива, аудио, видео и текста разные иконки.
