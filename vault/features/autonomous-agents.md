# Агенты

## Что это

Два разных зверя, которых пользователь не хочет смешивать.

**Субагенты** — помощники внутри текущего чата. Их видно у родительского чата, но они не
попадают в список чатов: «я этот чат не создавал». Агент должен пользоваться ими чаще,
чем сейчас, но навязывать их силой не надо.

**Независимые агенты** — самодостаточные исполнители на конкретную директорию. Они
крутятся сами и приводят документацию и описание проекта к рабочему, отполированному
виду. Один из них сравнивает слепок базы знаний с состоянием кода и приводит одно к
другому — это и есть разбор видения.

Пользователь не хочет дашборд: автономные агенты должны уместиться в нынешнюю модель
взаимодействия, то есть выглядеть как чаты, а не как отдельная консоль.

## Критерии приёмки

- В списке чатов нет чатов, созданных агентом без меня.
- У чата есть открывалка субагентов: видно действующих и законченных.
- Из приложения можно запустить независимого агента на директорию; он виден как чат и
  работает без моего сообщения.
- Независимый агент читает vault и код, предлагает расхождения в очередь разбора и не
  правит vault сам.
- Агент на директорию не создаёт коммит на каждый вызов инструмента.
